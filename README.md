# LoReal Estate + ZONAS CBA

Proyecto de Lore: zonas de Córdoba capital para comprar y vender.

- `LorealState/` — web (Netlify: https://loreal-state.netlify.app/).
- `ZonasCBA/` — app Android (APK en Releases → `zonascba-apk-latest`) y los datos de las zonas.
- Los datos viven en `ZonasCBA/app/src/main/assets/data/zonas.json`; la web y la app los leen de este repo (rama main),
  por eso el repo tiene que ser **público**.
